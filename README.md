Небольшой фановый проект для спавна банок чая.

Использовать в OBS "Захват игры" и использовать фильтр "Хромакей".



Управление:

Спавн банки - 1

Деспавн банки - 2

Очистить - 3

Сохранить - Ctrl + S

Загрузить - Ctrl + O

Настройки - P

Скролл - Колесико мыши



Загрузка своей картинки:

Форматы (.png .jpg .jpeg .bmp .webp .svg).

Размер картинки 400х400 (Желательно), можно и другой размер, но в таком случае картинка будет на всю банку, либо наоборот, слишком маленькая.
